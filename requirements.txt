Aura PWA - requirements to run
================================

This is a Node.js project (Vite). JavaScript packages are listed in
package.json, so "npm install" reads that file; there is nothing to pip install.

1. Software to install first
----------------------------
- Node.js 20 or newer (developed on Node 24) - https://nodejs.org
- npm (comes with Node.js)
- Git (to clone the repository)
- A browser with WebGPU and hardware acceleration enabled:
  Chrome or Edge 113+ on a computer with a supported GPU.
  The on-device tutor (web-llm) does not run without WebGPU.
  Check at chrome://gpu that "WebGPU" says "Hardware accelerated".

2. Install and run
-------------------
    npm install        # installs packages and copies OCR files into public/tesseract
    npm run dev        # starts the dev server (Vite prints the local URL)

Other commands:
    npm run build      # production build into dist/
    npm run preview    # serve the production build
    npm test           # run the unit tests
    npm run ocr:assets # re-copy the OCR files if public/tesseract is missing

4. Notes
--------
- No API keys or .env values are needed.
- The first run downloads the AI model (several hundred MB) and caches it in the
  browser, so an internet connection is needed once. After that it works offline.
- public/tesseract is generated by "npm install" and is not stored in git.
- Camera access needs https or http://localhost.
